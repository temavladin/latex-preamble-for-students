# LaTeX-преамбула для оформления отчетов по ГОСТ 7.32-2017

Шаблон и преамбула к компилятору XeLaTeX. Соблюдены требования ГОСТ 7.32-2017, правила оформления отчёта о научно-исследовательской работе.



# Быстрый старт

![Быстрый старт](img/quick-start.jpg)

# Титульные листы

![Примеры шаблонов титульных листов университета ГУАП](img/example-titles.png)

Для примера добавлен титульный лист для НИР в общем виде — `title_gost_example.tex` и четыре титульных листа для учебных отчётов университета ГУАП.

Используйте следующие команды, чтобы использовать соответствующие титульные листы.

Титульный лист ГУАП для курсовых работ:
```LaTeX
\include{title_guap_coursework}
```


Титульный лист ГУАП для практических работ:
```LaTeX
\include{title-pages/title_guap_practice}
```

Титульный лист ГУАП для лабораторных работ с шапкой министерства:
```LaTeX
\include{title-pages/title_guap_laboratory}
```

Титульный лист ГУАП для лабораторных работ без шапки министерства:
```LaTeX
\include{title-pages/title_guap_laboratory_old}
```
